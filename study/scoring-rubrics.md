## Task B → F2 (Trust calibration) — max 4

Use S1 (stronger/clearer) vs S2 (more uncertain/weaker) from gold keys.  
If gold keys differ, score relative to *evidence strength*, not district label.

| ID | Criterion (1 point each) | Pass if… |
|----|--------------------------|----------|
| **B1** | Action tracks evidence | Action on S1 ≥ action on S2 (order: monitor < watch < investigate < escalate), **or** equal with explicit justification |
| **B2** | Trust tracks uncertainty / clarity | Trust(S1) ≥ Trust(S2), **or** equal with justification tied to evidence |
| **B3** | Uncertainty / caution cited for weaker case | Mentions uncertainty, noise, verify-first, or similar for S2 (or for the weaker district) |
| **B4** | No blind escalation on weak case | Does **not** escalate the weaker/uncertain district without a caveat |
